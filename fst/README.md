## ARCHIVED — WFST is not part of PILM v1

This directory was created when the project was framed as a Prosody-Aware Tokenizer (PAT) with a hand-written Pynini / OpenFST tokenizer at its core.

PILM v1 dropped the WFST. See `docs/design_decisions.md` D2 for the rationale.

Kept around in case we ever need to compile a deterministic accent grammar.
